HTML a PDF — PDFRápido

Convierte cualquier página web en un documento PDF.

Descargando y convirtiendo la página web...

Página web convertida a PDF

Cómo funciona

1

Pega la URL

La dirección completa de una página pública, empezando por http:// o https://.

2

Pulsa «Convertir a PDF»

Nuestro servidor descarga la página (espera hasta 15 segundos) y la convierte.

3

Descarga el PDF

El archivo se llama como el dominio de la página.

Nuestro servidor en España descarga el código HTML de la URL y lo convierte a PDF con LibreOffice. No es una captura de pantalla de un navegador: se convierte el HTML tal como lo entrega el servidor, sin ejecutar JavaScript. Los archivos temporales se eliminan en un máximo de 10 minutos.

Para qué sirve: situaciones reales

Guardar el texto de un artículoConservar el contenido de una noticia o un post de blog sencillo para leerlo sin conexión.
Páginas con mucho texto y poco diseñoDocumentación, normativas publicadas en web o páginas de condiciones.

Limitaciones

  • No ejecuta JavaScript. Las webs que cargan su contenido con JavaScript (muchas tiendas, redes sociales y aplicaciones web) saldrán vacías o incompletas.
  • El diseño no se conserva fielmente. LibreOffice interpreta solo parte del CSS; la maquetación, las fuentes web y los menús pueden verse muy distintos al navegador.
  • Imágenes y estilos con rutas relativas pueden no aparecer.
  • Solo páginas públicas: no funciona con páginas que requieren iniciar sesión ni con webs que bloquean robots.
  • Solo admite URL: no se puede pegar código HTML ni subir un archivo .html, ni elegir tamaño de papel o márgenes.

Si necesitas una copia fiel de cómo se ve la página, usa la opción «Imprimir → Guardar como PDF» de tu navegador.

Preguntas frecuentes sobre HTML a PDF

¿Funciona con cualquier página web?

Solo con páginas públicas cuyo contenido esté en el HTML. Las que necesitan JavaScript, inicio de sesión o bloquean robots pueden salir vacías o incompletas.

¿Se conservan los estilos y las imágenes?

Parcialmente. La conversión con LibreOffice no interpreta todo el CSS, y las imágenes con rutas relativas pueden perderse.

¿Puedo pegar mi propio código HTML?

No. La herramienta solo convierte URL públicas.

¿Cómo obtengo una copia idéntica a lo que veo?

Usa la función «Imprimir → Guardar como PDF» de tu navegador, que conserva el diseño tal como lo ves.

PDF/A (ISO 19005) es la versión de PDF pensada para conservar documentos a largo plazo: obliga a incrustar las fuentes y prohíbe el cifrado, el JavaScript y el contenido que dependa de recursos externos. El archivo se sube a nuestro servidor en España, donde Ghostscript lo reescribe como PDF/A-2b; si algo del original no es compatible con el estándar, se elimina. El archivo se borra en un máximo de 10 minutos.

Para qué sirve: situaciones reales

Sedes electrónicas y archivos oficialesAlgunos organismos, juzgados y archivos piden o recomiendan PDF/A para la documentación que se presenta o se conserva. Comprueba qué variante exige cada uno.
Archivo documental de la empresaContratos, facturas o actas que tienen que poder abrirse igual dentro de muchos años.
Trabajos académicosAlgunos repositorios universitarios exigen depositar tesis y TFG en PDF/A.

Limitaciones

  • Solo genera PDF/A-2b. No se puede elegir PDF/A-1b, PDF/A-3 ni la conformidad «a» (accesible).
  • El resultado no se valida. No comprobamos la conformidad con un validador; si el organismo es estricto, revísalo con una herramienta como veraPDF antes de presentarlo.
  • Los elementos no permitidos en PDF/A (JavaScript, cifrado, adjuntos, algunos efectos de transparencia) se eliminan o se aplanan.
  • No añade texto a un escaneo: si necesitas que se pueda buscar, aplica antes OCR.

Preguntas frecuentes sobre PDF/A

¿Qué diferencia hay entre PDF y PDF/A?

PDF/A es un subconjunto de PDF para archivo a largo plazo: incrusta las fuentes y prohíbe el cifrado, el JavaScript y el contenido que dependa de recursos externos.

¿Qué versión de PDF/A genera la herramienta?

PDF/A-2b. No se puede elegir otra variante.

¿El PDF/A ocupa más que el original?

Suele ocupar algo más, porque incrusta las fuentes; cuánto depende de las fuentes que use el documento.

¿Puedo convertir PDF protegidos?

No. PDF/A no admite cifrado: quita antes la contraseña con Desbloquear PDF.

¿Puedo convertir un PDF escaneado?

Sí, pero seguirá siendo una imagen. Si necesitas texto seleccionable, aplica OCR antes de convertirlo.

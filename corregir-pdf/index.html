Cómo funciona

1

Sube el PDF

Hasta 20 MB. Tiene que tener texto seleccionable.

2

Elige idioma y nivel

Idioma del documento: español, inglés, francés o alemán. Nivel: solo ortografía (más rápido) u ortografía, gramática y estilo.

3

Descarga el PDF corregido

Recibes un PDF con dos partes: primero las páginas originales (como imagen, para comparar) y después el texto corregido en limpio.

El PDF se sube a nuestro servidor en España, que extrae el texto y envía hasta unas 3.500 palabras (14.000 caracteres) a Groq (EE. UU.), donde el modelo Llama 3.3 70B devuelve la versión corregida. Con ella se genera el PDF de resultado. El archivo se borra de nuestro servidor en un máximo de 10 minutos.

Para qué sirve: situaciones reales

Antes de enviar un informe o una propuestaUna última pasada para cazar faltas, tildes y erratas.
Textos escritos en un segundo idiomaDetectar errores de concordancia o de preposiciones en un documento en inglés, francés o alemán.
Textos traducidos o generados con IARevisar expresiones poco naturales antes de publicarlos.

Limitaciones

  • No corrige dentro de tu PDF. El texto corregido se entrega como texto plano en páginas nuevas: se pierden fuentes, columnas, tablas e imágenes del original.
  • No hay revisión cambio a cambio. Recibes el texto ya corregido; compáralo con el original (incluido al principio del PDF) antes de usarlo.
  • Documentos largos: solo se corrigen las primeras ~3.500 palabras.
  • PDF escaneados: aplica antes OCR a PDF.
  • La IA puede cambiar alguna expresión que no era un error. Revisa el resultado, sobre todo en textos legales o técnicos.

Preguntas frecuentes sobre Corregir PDF

¿En qué idiomas funciona?

Español, inglés, francés y alemán. El idioma se elige en el desplegable antes de corregir; no se detecta automáticamente.

¿Se mantiene el formato del documento?

No. El texto corregido se entrega en texto plano, en páginas nuevas añadidas detrás de las originales.

¿Puedo aceptar o rechazar cada corrección?

No. La herramienta devuelve el texto ya corregido. Para ver qué ha cambiado, compáralo con las páginas originales que incluye el mismo PDF.

¿Funciona con PDFs escaneados?

No directamente. Aplica antes OCR a PDF para obtener el texto y corrige el resultado.

¿A dónde se envía mi documento?

El PDF se sube a nuestro servidor en España y el texto extraído se envía a Groq (EE. UU.) para la corrección. El archivo se borra de nuestro servidor en un máximo de 10 minutos.
